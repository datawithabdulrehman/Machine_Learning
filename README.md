### 📝 Topics Covered

* **ML-01 (Regression Fundamentals):** Hands-on practice with basic regression algorithms using Heart & Insurance datasets.
* **ML-02 (Linear Regression Theory):** In-depth exploration of Linear Regression concepts paired with a Ford car price prediction model.
* **ML-03 (Classification & Web Deployment):** End-to-end classification pipeline featuring a KNN model for Heart Disease (deployed via `app.py`) and a detailed step-by-step model comparison on the Titanic dataset.
* **ML-04 (Advanced Machine Learning):** Advanced workflows including K-Means Clustering, Ensemble Learning methods, Hyperparameter Tuning using `GridSearchCV`, and Dimensionality Reduction using `PCA`.
* **Notes & Reference Materials:** Quick-reference cheat sheets for Supervised and Unsupervised learning, visual asset summaries, and interactive HTML notes.
